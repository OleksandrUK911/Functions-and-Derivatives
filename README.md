## 📚 Структура завдань

### Завдання 1: Лінійна функція оцінки від навчання
**Формула:** `f(x) = 10x - 5`

**Контекст:** Моделювання залежності оцінки студента від кількості годин навчання.

**Що виконується:**
- Обчислення похідної функції: `f'(x) = 10`
- Побудова графіків функції та похідної на інтервалі [0, 10]
- Аналіз швидкості зміни оцінки

**Ключові висновки:**
- Кожна додаткова година навчання збільшує оцінку на 10 балів
- Швидкість зростання оцінки є постійною (похідна = 10)
- Лінійна залежність вказує на пропорційний зв'язок між зусиллями та результатом

**Бібліотеки:** `numpy`, `matplotlib`, `sympy`

---

### Завдання 2: Тригонометричні та логарифмічні функції
**Формули:** 
- `f₁(x) = sin(x)`
- `f₂(x) = ln(x)`

**Що виконується:**
- Обчислення похідних:
  - `sin(x)' = cos(x)`
  - `ln(x)' = 1/x`
- Візуалізація обох функцій та їх похідних
- Порівняльний аналіз поведінки

**Особливості візуалізації:**
- Для `sin(x)`: діапазон від -2π до 2π (демонструє періодичність)
- Для `ln(x)`: діапазон від 0.1 до 10 (уникнення невизначеності при x=0)

**Ключові спостереження:**
- `sin(x)` та `cos(x)` демонструють періодичні коливання зі зсувом фази
- `ln(x)` зростає повільно, а її похідна `1/x` монотонно спадає
- При великих значеннях x швидкість зростання ln(x) прямує до нуля

**Бібліотеки:** `numpy`, `matplotlib`, `sympy`

### Завдання 3: Квадратична функція витрат виробництва
**Формула:** `f(x) = x² - 5x + 1`

**Контекст:** Моделювання загальних витрат компанії залежно від обсягу виробництва.

**Що виконується:**
- Обчислення похідної: `f'(x) = 2x - 5`
- Візуалізація на інтервалі [0, 100]
- Економічний аналіз функції витрат

**Економічна інтерпретація:**
- **Похідна** представляє **граничні витрати** (marginal cost)
- При `x < 2.5`: граничні витрати від'ємні → ефект масштабу
- При `x = 2.5`: мінімум витрат (критична точка)
- При `x > 2.5`: витрати зростають з кожною додатковою одиницею

**Практичне застосування:**
Допомагає бізнесу визначити оптимальний обсяг виробництва для мінімізації витрат.

**Бібліотеки:** `numpy`, `matplotlib`, `sympy`

## 🎓 Теоретична основа

### Визначення похідної:
Похідна функції в точці показує швидкість зміни функції у цій точці і є кутовим коефіцієнтом дотичної до графіка.

### Основні правила диференціювання:
- `(xⁿ)' = n·xⁿ⁻¹`
- `(sin x)' = cos x`
- `(ln x)' = 1/x`
- `(c·f)' = c·f'` (де c — константа)
